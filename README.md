Cluster Patient Lifestyle Data to Discover Health Risk Groups

Project Description

This project uses Data Science and Analytics techniques to group patients based on their lifestyle data and identify different health risk patterns.

Technologies Used

- Python
- Pandas
- NumPy
- Matplotlib
- Scikit-learn
- K-Means Clustering

Project Workflow

1. Load the patient lifestyle dataset.
2. Check missing values and clean the dataset.
3. Visualize patient lifestyle data.
4. Apply K-Means clustering.
5. Analyze and visualize the patient groups.

Expected Outcome

The project groups patients with similar lifestyle characteristics for exploratory analysis.

Note: This project is for educational purposes and does not provide medical diagnoses.
